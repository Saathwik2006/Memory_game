# 🧠 Memory Game

A simple and interactive browser-based **Memory Matching Game** built using HTML, CSS, and JavaScript.

The goal is to find all matching pairs of cards with the minimum number of moves.

## 🎮 Features

- 🃏 Interactive card flipping
- 🔀 Random card shuffling
- 🎯 Match detection
- 🔢 Move counter
- 🏆 Winner detection
- 🔄 Play Again / Restart functionality
- ✨ Card flip animations
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 🕹️ How to Play

1. Click on any card to reveal its symbol.
2. Click on another card to reveal the second symbol.
3. If both cards match, they remain open.
4. If they don't match, the cards are flipped back.
5. Continue matching cards until all pairs are found.
6. Once every pair is matched, you win the game.
7. Click **Play Again** to start a new game.
